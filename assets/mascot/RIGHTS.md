# Original simple vector host

Created for this AI Towkay Lab project from basic geometric shapes. No third-party
character, footage, face or voice was used as a reference asset. The SVGs are
editable source assets; their geometry also lives in `mascot.py`. No external
asset attribution is required for these original shapes. This is a simple vector
mascot, not a commissioned or premium illustration. Review branding before use.

The video uses the system-installed DejaVu Sans font under its distributed font
licence. No font binary is bundled in the repository. On Debian, the licence is
available in `/usr/share/doc/fonts-dejavu-core/copyright`.
